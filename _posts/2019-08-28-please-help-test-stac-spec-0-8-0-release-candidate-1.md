Just a quick note, the core team working on [SpatioTemporal Asset Catalog (STAC)](https://github.com/radiantearth/stac-spec) has lot of great improvements for the [0.8.0 release](https://github.com/radiantearth/stac-spec/releases/tag/v0.8.0-rc1). But we want to be sure a wider audience reviews our numerous changes, so we can be sure that we’ve got it right and don’t need to immediately issue a 0.8.1.

So if you’ve got a STAC-compliant catalog it would be great if you could update it to the latest version and give us feedback before we finalize 0.8.0. And if you build software that reads or generates catalogs then now is a great time to try out the new version and make sure it works.

We’ve had a ton of great changes in over 200 commits, including lots of API improvements, new extensions, and lots of great cleanup. You can read the [release notes](https://github.com/radiantearth/stac-spec/releases/tag/v0.8.0-rc1) for the full changelog, or check the image below. And we’ll walk through all the improvements made in detail for the 0.8.0 release announcement!
